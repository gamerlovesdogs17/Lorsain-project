# Azgaar source provenance

These files are the original map-generator exports used to derive Lorsain/Terena geography. They are **not runtime game assets**. The game should consume the cleaned files in `/data` and `/maps`; raw Azgaar IDs enter the canonical model only through `data/canonical_crosswalk.json`.

The latest canonical editable save in this folder is `Lorsain 2026-08-12-20-29.map`. The SVG export is the source vector snapshot used during canonicalization.

Some files are large. Do not attach/index them in Cursor unless a geography repair task specifically needs them.
