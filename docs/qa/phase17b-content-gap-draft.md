## Content variety audit

### Repeated reskins / noun swaps
- Housing-adjacent bills that differ mainly by title
- Foreign crisis labels that recycle stage language
- Court fact patterns with similar warrant/rights framing
- Generic “ministry under pressure” notes after reshuffles

### Overly frequent
- Near-template news items with collapsed date/number fingerprints
- NPC regulation attempts when ministries rotate
- “Too early to assess” minister performance after reshuffles

### Almost never triggers
- Minister scandals / investigations / resignations
- Coalition red-line breach *narrative* (share shortfall is mechanical)
- Distinct ministry-domain crises (housing vs defence vs finance)
- Amending-legislation follow-through after implementation request
- Trade-war / sanctions spiral scenarios

### Exhausts after 10–20 years
- Promise tracker after early platform items resolve
- Organization campaigns without refresh pools
- Foreign crisis deck if templates are exhausted

### Missing policy domains
- Fiscal consolidation politics (austerity bargains, pension fights)
- Migration / housing interaction crises
- Energy security vs climate as cabinet fights
- Judicial appointment scandals tied to confirmation votes
- Provincial–federal funding standoffs tied to implementation negotiate outcomes

## Recommended Phase 17B implementation order

1. **Legislation / policy / implementation** — distinctive bill families, implementation complications, amending follow-through (not reskins)
2. **Budgets / fiscal disputes** — use real envelope-vs-request conflict as content hooks
3. **Parties / Caucuses / leadership / organizations** — endorsements + lobbying campaigns (leadership/caucus already strong)
4. **Campaigns / politicians / scandals** — biographies + scandal arcs (highest variety debt)
5. **Courts / Constitution / provinces** — doctrine packages + federal–provincial standoffs
6. **Foreign Affairs** — crisis/treaty/trade/sanctions scenario depth without recycling stage language
7. **News / history templates** — reduce fingerprint collapse; expand non-reskin templates
8. **Repetition / frequency balancing** — throttle over-frequent empties; refresh pools that exhaust
